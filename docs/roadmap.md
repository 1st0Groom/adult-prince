# 개발 순서

1. 기반: 확정 기획과 직업 규격, 게임 상태 엔진 → 현재 착수
2. 생활: 작은 1인칭 공간, 집·학교 이동, 상호작용과 수면
3. 대화: 선택지·자유 입력, NPC 기억 조회, AI 연결 및 오류 처리
4. 업무: 반도체 설비 유지보수 교육 체험과 결과 반영
5. 연결: 며칠의 사건, 직업 기회, 준비 방향, 저장·재개
6. 확장: 검토된 직무 데이터를 가져와 추가 시나리오를 순차 제작

## 미정 사항
웹 화면 도구 확정, API 프레임워크, 로컬 GPU와 사용 가능 VRAM, Qwen 4B Instruct 정확한 모델 ID·실행 방식, BGE-M3 검색 구성, 에셋 출처·라이선스, 첫 장비와 직무 절차, 첫 시나리오의 완료 기준.

## 완료 기준
상태 엔진은 결정적 결과·잘못된 행동 거절·상태 불변성을 검증한다. 플레이 버전은 이동→대화→약속→체험→결과→저장·재개를 실제로 확인한 뒤 완료로 기록한다.
